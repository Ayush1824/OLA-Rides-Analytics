## 📌 Project Overview  
This project provides an **end-to-end data analytics solution** for OLA Ride bookings.  
Using **SQL, Power BI, and Streamlit**, we analyze booking trends, revenues, cancellations, and ratings to deliver **business insights**.  

---

## 🎯 Objectives  
- Query ride data using **SQL** to extract insights.  
- Build **Power BI dashboards** for visualization.  
- Develop an interactive **Streamlit app** integrating SQL queries & Power BI.  
- Provide **business-oriented insights** for decision making.  

---

## 🛠️ Tech Stack  
- **SQL (MySQL)** → Data storage & analysis  
- **Python (Pandas, SQLAlchemy, Streamlit)** → Data processing + interactive UI  
- **Power BI** → Dashboard design & KPIs  
- **GitHub** → Version control & project documentation  

---

## 📊 Features  

### 🔹 SQL Analysis  
✔ Retrieve all successful bookings  
✔ Find average ride distance by vehicle type  
✔ Revenue analysis by payment method  
✔ Identify top 5 customers by total booking value  

### 🔹 Power BI Dashboard  
- **Overall View** → Ride volume trend, booking status breakdown  
- **Vehicle Type Analysis** → Top 5 vehicle types by distance covered  
- **Revenue Analysis** → Revenue by payment method, Top 5 customers  
- **KPIs** → Total bookings, completed rides, revenue, avg ratings  

👉 [🔗 View Power BI Dashboard](https://app.powerbi.com/view?r=eyJrIjoiODBhOWE4NzYtNDE3OC00YzVjLThhOWMtYzI5ZTc1NTA0ZDU2IiwidCI6IjFjZWYyNzBmLWEzNjItNGNlNy05NDM1LTA2NzUxMmMyNjAzMSJ9)  

### 🔹 Streamlit Application  
- Sidebar filters (Vehicle Type, Payment Method, Status)  
- SQL query results displayed in tables  
- KPI cards for quick insights  
- Embedded live Power BI dashboard
